## 개요
- C# 프로그래밍 학습
- 1줄 소개: 햄버거 및 추가 옵션 선택 키오스크
- 사용한 플랫폼: 
	- C#, .NET Windows Forms, Visual Studio, GitHub
- 사용한 컨트롤:
	- 입력 컨트롤: RadioButton (메인 메뉴 단일 선택), CheckBox (추가 옵션 다중 선택)
	- 표시 및 알림: ListBox (주문 내역 리스트 출력), Label (총 금액 표시 및 에러 메시지 안내)
	- 실행 컨트롤: Button (주문하기, 초기화), GroupBox (카테고리별 UI 그룹화)
- 사용한 기술과 구현한 기능: 
	- 실시간 반응형 주문 로직: '주문하기' 버튼 의존성을 탈피하여, RadioButton과 CheckBox의 상태 변경 시 즉시 금액과 내역이 갱신되는 이벤트 기반 프로그래밍 구현
	- 키보드 접근성 및 UX 최적화:
		- TabIndex 설정을 통한 논리적 포커스 이동 구현
		- AcceptButton 지정을 통해 어느 위치에서든 Enter 키로 주문 실행 가능
	- 커스텀 라디오 버튼 제어: AutoCheck 속성을 수동으로 제어하여 방향키 이동 시 자동 선택을 방지하고, 스페이스바 또는 마우스 클릭 시에만 메뉴가 확정되도록 설계
	- 동적 UI 피드백 및 예외 처리:
		- 메뉴 미선택 시 Label의 텍스트 줄바꿈(\n), 색상 변경(Color.Red), 폰트 크기 확대(11pt, Bold)를 통한 인라인 에러 처리
		- 정상 주문 시 폰트 스타일 및 색상을 초기 상태(파란색, 기본 크기)로 자동 복구
	- 데이터 가공 및 포맷팅: ToString("N0") 메서드를 활용하여 결제 금액에 세 자리마다 콤마(,)를 삽입하는 화폐 단위 출력 포맷 적용
	- 완전 초기화 시스템: 초기화 버튼 클릭 시 모든 선택 해제, 금액 리셋, 리스트박스 클리어는 물론, 탭 순서 유지를 위한 TabStop 보정 및 포커스 초기화 로직 구현

	- 예외 상황 가시성 강화: 사용자가 메인 메뉴를 선택하지 않고 주문을 시도했을 때, 시스템이 이를 감지하고 직관적인 경고를 보냅니다.
	- 동적 UI 스타일링: 정적인 화면 구성에서 벗어나 상황에 따라 폰트 크기, 색상, 레이아웃(줄바꿈)을 실시간으로 변경하여 경고의 전달력을 높입니다.
	- 다중 속성 제어: 에러 발생 시 레이블의 텍스트를 두 줄로 나누어 출력(\n 활용)하고, 동시에 폰트 크기를 11pt로 키워 일반 상태와 확연히 구분되도록 구현하였습니다.
	- 조건부 로직 및 흐름 제어: if 조건문을 통해 라디오 버튼의 선택 여부를 판별하고, 선택되지 않았을 경우 return을 사용해 불필요한 계산 로직이 실행되지 않도록 차단하였습니다.
	- UI 상태 복구: 정상적인 주문이 진행될 때는 빨간색으로 변했던 폰트 색상을 다시 검정색으로, 커졌던 폰트를 다시 기본 크기(9pt)로 되돌려 UI의 일관성을 유지하였습니다.
	- Font 클래스 동적 할당: new Font()를 사용하여 런타임 중에 컨트롤의 폰트 패밀리, 크기, 스타일(Bold)을 변경하는 기술
	- 문자열 이스케이프 시퀀스: \n과 문자열 연결 연산자(+)를 이용한 멀티라인 텍스트 출력
	- Color 구조체 활용: System.Drawing.Color를 이용한 시각적 피드백 시스템 구축
	- 예외 방어 코드: 논리 연산자(!, &&)를 활용한 필수 입력 항목 누락 검증

![실행화면](img/screenshot-3.gif)

- 구현한 내용 (위 그림 참조)
	- 완전한 키보드 접근성 확보: 마우스 조작 없이 Tab, 방향키, Space, Enter 키만으로 메뉴 선택부터 주문 완료까지 가능한 환경을 구축합니다.
	- 사용자 조작 동선 최적화: 사용자의 시선 흐름에 맞춘 논리적인 포커스 이동 순서를 설계하여 결제 프로세스를 단축합니다.
	- Tab Order 최적화: TabIndex 속성을 재설정하여 Tab 키 입력 시 [메뉴 선택] -> [추가 옵션] -> [주문하기] -> [초기화] 순으로 포커스가 자연스럽게 이동하도록 구현하였습니다.
	- 전역 수락 버튼(AcceptButton) 지정: 폼의 AcceptButton 속성을 btnOrder로 설정하여, 어느 컨트롤에 포커스가 있더라도 Enter 키를 누르면 즉시 주문 로직이 실행되도록 하였습니다.
	- 그룹 내 자동 탐색: GroupBox로 묶인 라디오 버튼들 사이를 방향키로 자유롭게 이동하며 선택할 수 있도록 설계하여 조작 편의성을 높였습니다.
	- TabIndex 제어: Visual Studio의 '탭 순서' 편집 기능을 이용한 컨트롤 내비게이션 설계
	- 폼 수준의 키 이벤트 핸들링: AcceptButton 속성을 통한 엔터키 입력과 버튼 클릭 이벤트의 연동
	- Focus 시각화: 키보드 사용자가 현재 위치를 명확히 알 수 있도록 포커스가 위치한 컨트롤의 점선 테두리 및 강조 효과 활용
	- 컨트롤 간 포커스 전이: 특정 조건 만족 시 다음 단계 컨트롤로 Focus() 메서드를 호출하여 흐름을 유도하는 기술

	- 입력 정교화 및 UX 커스텀: 라디오 버튼의 기본 동작(방향키 이동 시 자동 선택)을 제한하고, 사용자의 명확한 의도(클릭 또는 스페이스바)가 있을 때만 데이터가 반영되도록 제어합니다.
	- 이벤트 기반 실시간 동기화: RadioButton과 CheckBox의 선택 상태가 변할 때마다 합계 계산 함수를 호출하여, 리스트박스와 합계 레이블이 항상 최신 상태를 유지하게 했습니다.
	- 포커스 이동과 선택의 분리: 라디오 버튼의 AutoCheck 속성을 활용하여, 방향키로는 포커스만 이동시키고 실제 메뉴 확정은 Space 키나 마우스 클릭으로만 가능하게 하여 오조작을 방지하였습니다.
	- UI 일관성 유지: 초기화 버튼 클릭 시 모든 선택을 해제함과 동시에, 다시 탭(Tab) 키를 눌렀을 때 메뉴 그룹부터 정상적으로 포커스가 진입하도록 TabStop 및 포커스 로직을 보완하였습니다.
	- 이벤트 핸들러 통합 관리: 다수의 컨트롤 이벤트를 하나의 업데이트 로직으로 연결하여 코드의 재사용성을 높이는 기술
	- AutoCheck 속성 수동 제어: WinForms의 기본 선택 메커니즘을 오버라이딩하여 커스텀 선택 로직(KeyDown, Click 이벤트 결합)을 구현
	- 동적 상태 복구: btnInit_Click 발생 시 모든 인덱스와 시각적 속성(Color, Font)을 초기 상태로 되돌리는 완전 초기화 로직
	- 조건부 데이터 바인딩: 선택된 항목의 유무를 실시간으로 판별하여 경고 메시지와 정상 금액 표시 사이를 유연하게 전환하는 기술
