## 실행 화면 (과제1)
- 과제1 코드의 실행 스크린샷

![과제1 실행화면](img/screenshot-1.gif)

- 과제 내용:
	- 키오스크 기본 UI 구성: 라디오 버튼(메뉴 선택), 체크박스(옵션 선택), 리스트박스(주문 내역), 버튼(주문/초기화) 등을 배치하여 표준적인 키오스크 화면을 설계합니다.
	- 주문 합산 로직 구현: 사용자가 선택한 메뉴와 옵션의 가격을 실시간으로 계산하여 총 금액을 산출하는 기능을 구현합니다.
	- 데이터 초기화: '초기화' 버튼을 통해 모든 선택 사항과 결제 금액을 0으로 되돌리는 기능을 구축합니다.

- 구현 내용과 기능 설명:
	- 컨트롤 그룹화: GroupBox를 사용하여 '메뉴 선택'과 '추가 옵션' 영역을 시각적으로 분리하여 사용자 혼선을 방지했습니다.
	- 실시간 리스트박스 업데이트: '주문하기' 버튼 클릭 시 선택된 항목들을 lstOrder에 순차적으로 출력하여 영수증과 같은 효과를 주었습니다.
	- 세 자리 콤마 포맷팅: totalCost.ToString("N0")을 적용하여 큰 금액도 한눈에 읽기 쉽도록 구현하였습니다.

- 사용한 기술과 구현한 기능:
	- 기본 컨트롤 활용: RadioButton, CheckBox, ListBox, Button의 핵심 속성 제어
	- 금액 합산 알고리즘: 전역 변수를 활용한 누적 계산 및 btnOrder_Click 시 totalCost = 0 초기화 후 재계산 로직 적용

## 실행 화면 (과제2)
- 과제2 코드의 실행 스크린샷

![과제2 실행화면](img/screenshot-2.gif)

- 과제 내용:
	- 예외 상황 가시성 강화: 사용자가 메인 메뉴를 선택하지 않고 주문을 시도했을 때, 시스템이 이를 감지하고 직관적인 경고를 보냅니다.
	- 동적 UI 스타일링: 정적인 화면 구성에서 벗어나 상황에 따라 폰트 크기, 색상, 레이아웃(줄바꿈)을 실시간으로 변경하여 경고의 전달력을 높입니다.

- 구현 내용과 기능 설명:
	- 다중 속성 제어: 에러 발생 시 레이블의 텍스트를 두 줄로 나누어 출력(\n 활용)하고, 동시에 폰트 크기를 11pt로 키워 일반 상태와 확연히 구분되도록 구현하였습니다.
	- 조건부 로직 및 흐름 제어: if 조건문을 통해 라디오 버튼의 선택 여부를 판별하고, 선택되지 않았을 경우 return을 사용해 불필요한 계산 로직이 실행되지 않도록 차단하였습니다.
	- UI 상태 복구: 정상적인 주문이 진행될 때는 빨간색으로 변했던 폰트 색상을 다시 검정색으로, 커졌던 폰트를 다시 기본 크기(9pt)로 되돌려 UI의 일관성을 유지하였습니다.

- 사용한 기술과 구현한 기능:
	- Font 클래스 동적 할당: new Font()를 사용하여 런타임 중에 컨트롤의 폰트 패밀리, 크기, 스타일(Bold)을 변경하는 기술
	- 문자열 이스케이프 시퀀스: \n과 문자열 연결 연산자(+)를 이용한 멀티라인 텍스트 출력
	- Color 구조체 활용: System.Drawing.Color를 이용한 시각적 피드백 시스템 구축
	- 예외 방어 코드: 논리 연산자(!, &&)를 활용한 필수 입력 항목 누락 검증
